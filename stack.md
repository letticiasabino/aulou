# Aulou Stack

- Next.js App Router e TypeScript para o app full-stack.
- Tailwind CSS e componentes locais inspirados em shadcn/ui.
- Supabase para Auth, Postgres, Storage privado e RLS.
- Zod, React Hook Form e TanStack Query preparados no frontend.
- OpenAI atras de provider abstrato, com fallback mock local.
- Netlify e o destino preferencial do app Next.js nesta fase.
- Render fica reservado para worker/OCR quando processamento assincrono justificar um servico separado.
