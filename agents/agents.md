# Aulou Agent Rules

- Ler a documentacao do produto antes de alterar arquitetura, banco ou seguranca.
- Manter regras de negocio em engines e services, nunca em componentes visuais.
- Nunca versionar credenciais ou dados reais.
- Executar format, typecheck, lint, testes e build quando as dependencias estiverem disponiveis.
- Registrar decisoes de hosting, marca e compatibilidade em `rules/DECISION-LOG.md`.
