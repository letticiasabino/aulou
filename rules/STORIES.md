# Aulou User Stories

- Como estudante, quero enviar meu cronograma para nao cadastrar cada prazo manualmente.
- Como estudante, quero revisar eventos extraidos antes de salvar para manter controle.
- Como estudante, quero ver prioridades e proximos prazos em uma agenda simples.
- Como estudante, quero conversar com um tutor contextualizado pelos meus materiais.
