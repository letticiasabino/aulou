# Production Checklist

- [x] Build, typecheck, lint, unit tests and E2E locais.
- [x] Health check versionado.
- [x] Variáveis documentadas sem valores reais.
- [x] Feedback com migration/RLS versionados.
- [x] Auth callback versionado.
- [ ] Projeto Vercel/Netlify criado e deploy publicado.
- [ ] URL de produção e health check validados.
- [ ] Supabase Production criado.
- [ ] Migrations aplicadas e verificadas.
- [ ] Auth redirects configurados.
- [ ] Storage privado confirmado.
- [ ] RLS testado com dois usuários.
- [ ] Backups e retenção verificados.
- [ ] Termos e Privacidade revisados juridicamente.
- [ ] Smoke test de produção executado.

Itens não marcados estão `BLOQUEADOS POR ACESSO EXTERNO` ou aguardam configuração manual.
